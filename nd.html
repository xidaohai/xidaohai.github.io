模型解释与边界

本页按经典式 ID = log₂(2D/W) 计算，不自动把负值截断为零。若 W ≥ 2D，公式输出不再适合作为通常意义上的非负难度解释；MT* 将标记为不适用。

实际菲茨定律通常使用 MT = a + b·ID，其中 a、b 由具体任务的实验数据估计。本页 MT* 只是设定 a = 0、b = 1 后的归一化演示。参考综述

1954 菲茨原始实验档案与动作机制

1. 受试人群与样本量：原论文中的两组往复敲击实验分别报告 16 名惯用右手的大学男性受试者。1 盎司与 1 磅两种笔杆负重条件使用不同受试者组，并非同一批 16 人完成两种负重。研究由俄亥俄州立大学团队开展，并获美国空军相关研究合同支持；这不等于所有受试者均来自航空心理学实验室。

2. 任务形态与参数：15 秒连续往复敲击（Reciprocal Tapping），每次试验后安排休息。靶板宽 W 为 0.25–2.0 英寸（约 0.635–5.08 cm），两靶中心间距/运动幅度 A 为 2–16 英寸（约 5.08–40.64 cm），由 4 种靶宽和 4 种幅度组成 16 种条件，名义 ID 覆盖 1–7 bits。失误率随条件变化，并非统一控制在 1.24%；最困难条件（W = 0.25 英寸、A = 16 英寸）在表中分别约为 3.65%（1 盎司）和 4.08%（1 磅）。

3. 定位动作机制：原论文报告各条件下的平均运动时间和失误率，但未确立“ID ≤ 2（＜200 ms）必然一次弹道直达”或“ID ≥ 3.5（＞400 ms）必然触发粗冲刺加 1 至数次闭环微调”的固定阈值。粗运动加精细微调可以作为后续运动控制或 FPS 瞄准机制的解释假设，但需要独立实验验证，不能当作 1954 年实验直接证明的结论。

4. 简化归一化模型（MT* ≡ ID）：若在经典线性关系 MT = a + b·ID 中人为设定 a = 0、b = 1，便可严格得到本页面使用的 MT* = ID。这是便于比较的归一化演示设定，不是原始实验回归得到的实际时间参数，也不是实际瞄准耗时预测。原始论文：Fitts (1954)

变体定义与约定

量纲：参考长度固定为 L₀ = 1 cm。Dphys × L₀ / Wphys² 才是严格无量纲的比值；当距离、直径都以 cm 的数值代入时，因为 L₀ = 1 cm，计算数值与此前直接使用 cm 数值的形式一致。若更换长度单位，必须同步换算 L₀。

接触边界：当 D ≤ W/2，起点位于球体内部或边界上，页面按你的模型约定将 ID_alt 设为 0。该分段规则与分离状态下的对数公式在边界附近并不连续；这是模型约定，需要在解释结果时保留。实际绘制直径小于 0.2 cm 时，隐藏球心白点和其他装饰细节，以免它们遮盖毫米级小球。

解释范围：灵敏度耦合是公式的代数性质。是否更贴近 FPS 瞄准行为，以及 ID 与动作耗时、单次定位/微调之间的关系，仍需通过实际瞄准任务实验验证。
